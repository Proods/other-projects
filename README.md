Project 1 - Software Engineering

This project utilizes the Micronaut framework, a lightweight alternative to Spring Boot, to develop a scalable and efficient backend microservice. The microservice emulates a video platform backend, enabling core functionalities such as user creation, video uploads, and user interactions. Users can like or dislike videos, and the system keeps track of the number of views, likes, and dislikes for each video. Additionally, the platform includes subscription and trending hashtag features.
To enhance scalability and responsiveness, the system follows an event-driven architecture using Kafka, ensuring efficient processing of user interactions and real-time updates. Additionally, it adopts Model-Driven Development with EMF (Eclipse Modeling Framework) to streamline the design and implementation of the system’s data models. The application is also containerized using Docker, making it well-suited for a modern microservices architecture.

Project 3 - Computer Vision

A research study was conducted at the University of Leeds to compare the virtual locomotion of simulated worms with real worms moving on agar plates under varying conditions, with the objective to validate existing models and formulate new hypotheses. The aim of my project is to develop a supplementary skeletonization programme to assist in the research. Using computer vision with Python, the programme generates the skeleton as a digital representation of a microscopic worm that accurately describes the posture and motion of the worms.


Project 4 (Upon request) - Game development

Developed a 2D game in Java, inspired by Overcooked, with a focus on teamwork and structured development. The project was divided into key deliverables, with tasks delegated among team members to maximize efficiency. Adopted an agile approach, working in sprints to ensure continuous improvement, seamless collaboration, and iterative feature enhancements. In the second phase of the assessment, we switched projects with another team, taking on their existing work to identify areas for improvement, apply fresh perspectives, and collaborate cross-functionally. This process deepened our understanding of game development while encouraging adaptability and team synergy.
